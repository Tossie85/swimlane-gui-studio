記法と保存機能について

この図について

スイムレーン図は Mermaid に相当する記法が無いため、このツール専用の記法（.swim）で表現しています。図はブラウザ内で直接SVGとして描画しており、外部ライブラリは使いません。

記法（.swim）

swimlane
    title "受注フロー"
    direction LR

    lane sales "営業部" #FFF9C4
    phase p1 "受付"

    node n1 "申込を受ける" lane=sales phase=p1 shape=start
    node n2 "内容を確認"   lane=sales phase=p1

    n1 -> n2 "確認依頼"

lane= や phase= のような名前付き属性にしているため、後から項目を増やしても古いファイルをそのまま読み込めます。direction は LR（左から右）と TB（上から下）が指定でき、TD は TB と同じ扱いです。2行目以降のインデントは Mermaid の記法にならった見た目上の調整で、あってもなくても図の内容には影響しません。

開始・終了の「●」

接続の from に [*] を選ぶと開始（●）、to に選ぶと終了（◉）が、相手と同じレーン・同じフェーズに作られます。開始は接続先の手前（LRなら左／TBなら上）、終了は先（右／下）に、位置を揃えて描かれます。そのあとは普通の図形として位置や所属を変更できます。図形の「形」から直接追加することもできます。

保存（エクスポート）

.swim 保存
レーン・図形・色・接続をすべて含んだ、このツールの保存形式です。「ファイルを開く」で読み込めば続きから編集できます。
.svg 保存
表示中の図を画像（SVG）として保存します。資料やスライドへの貼り付け用です。
.png 保存
表示中の図を画像（PNG）として保存します。SVGを扱えない場所（SNSの告知、チャット、Wiki）への貼り付け用です。拡大しても粗くならないよう、画面の2倍の大きさで書き出します。
.html 保存
ブラウザでそのまま開ける単独HTMLとして保存します。図はSVGで埋め込まれるため、外部通信なしで表示できます。

操作

一覧の ⠿ をドラッグすると並べ替えできます。プレビュー上の図形や矢印をクリックすると、対応する項目が編集状態になります。図形以外の場所をクリックすると編集を解除します。

色の指定には ↩ 戻す（ひとつ前の色に戻す／最大20件）と 既定に戻す（色の指定をやめる）があります。編集する項目を切り替えると履歴はリセットされます。

ヘッダーの キャンバス は、図のまわり（地）の色の設定です。図そのものは白地で描かれるので見え方は変わりません。この設定は保存物（.swim / .svg / .png / .html）には含まれません。

このツールについて

スイムレーン図（業務フロー図）をGUIで組み立てるツールです。入力内容はブラウザの外に送信されません。

使用ライブラリ

なし（外部通信なし）
.swim の解析とSVG描画は、自作の swimlane.js（下記）で行っています。サードパーティ製ライブラリ・外部通信ともにありません。ライブラリは npm と GitHub で公開しています（MIT）。

VS Code の Markdown で ```swimlane を使う

拡張機能「Swimlane Diagram Preview」を入れると、VS Code 標準の Markdown プレビュー（Ctrl+Shift+V）で ```swimlane ブロックが図として表示されます。このツールの「Markdownとしてコピー」は、そのまま貼り付けられる形で出力します。

自分のサイトのMarkdownで ```swimlane を使えるようにする

Mermaidと同じように、自分のサイトのMarkdown記法に ```swimlane フェンスコードブロックを組み込みたいサイト管理者向けの手順です（tossie85 lab自体もこの方式で記事内に埋め込んでいます）。

marked.js や markdown-it など多くのMarkdown変換ライブラリは、既定で ```swimlane ブロックを <pre><code class="language-swimlane"> として出力します（CommonMark準拠）。ページ読み込み後に以下のスクリプトを実行すれば、それらを図に置き換えられます。

<script src="https://cdn.jsdelivr.net/npm/swimlane-diagram@1.3.0/swimlane.js"></script>
<script>
  document.querySelectorAll('pre code.language-swimlane').forEach(function(codeEl){
    var pre = codeEl.closest('pre');
    var result = Swimlane.render(codeEl.textContent);
    if(result.ok){
      pre.outerHTML = result.svg;
    }else{
      pre.textContent = '記法エラー:\n' + result.errors.join('\n');
    }
  });
</script>

自作のMarkdownパーサーでフェンスの言語ごとに出力先タグを変えられる場合（PHPのParsedownなど）は、<pre class="swimlane">元のコード</pre> のように直接出力し、上と同じ要領で pre.swimlane を対象に Swimlane.render() を呼ぶ方がシンプルです。

ライブラリとして他サイトで使う

この解析・描画エンジンは swimlane.js 1ファイルに切り出してあり、他のWebサイトにそのまま組み込めます（外部通信なし・依存ライブラリなし・MIT）。入手の仕方は3つあります。

npm
npm install swimlane-diagram
Node.js から使う場合や、自分のビルドに取り込む場合はこれ。
CDN（jsDelivr）
https://cdn.jsdelivr.net/npm/swimlane-diagram@1.3.0/swimlane.js
版を固定して読み込んでください（@1.3.0 を外すと、次の版が出たときに図の見た目が変わることがあります）。
ファイルを置く
GitHub から swimlane.js を落として、自分のサーバーに置いても構いません。1ファイルだけで動きます。
<script src="https://cdn.jsdelivr.net/npm/swimlane-diagram@1.3.0/swimlane.js"></script>
<div id="diagram"></div>
<script>
  Swimlane.renderTo('#diagram', `swimlane
    title "受注フロー"
    direction LR

    lane sales "営業部"
    node n1 "申込を受ける" lane=sales shape=start
    node n2 "内容を確認"   lane=sales

    n1 -> n2 "確認依頼"
`);
</script>

主なAPI：

Swimlane.renderTo(el, code)
.swim コードから図を描き、指定した要素（セレクタ文字列 or DOM要素）に直接SVGを描画します。戻り値は render() と同じです。
Swimlane.render(code)
DOMを触らず { ok, svg, width, height, errors, state } を返します。SVG文字列を自分で使いたいときに。
Swimlane.parse(code) / .generate(state)
.swim ⇄ 状態オブジェクトの相互変換です。このツールの「コード直接編集」欄も内部で同じ関数を使っています。

記法（.swim）はこのツールの ❓ ボタンの説明と共通です。
